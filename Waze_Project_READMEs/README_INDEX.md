# Waze Project README Pack

This archive contains three high-level README files based on the supplied notebooks:

1. `README_Course_1_Foundations_of_Data_Science.md` — initial data inspection and preparation.
2. `README_Course_2_Go_Beyond_the_Numbers.md` — exploratory data analysis and visualizations.

Each README documents the stated data source, workflow, cleaning decisions, findings, limitations, and reproducibility notes. The notebooks describe the CSV as supplied in the Coursera lab environment; they do not document a public download URL.
